# 看牙有谱 · 手机网页版

本项目是原微信小程序的独立网页版本。使用原生 HTML/CSS/JavaScript；前端无 npm 运行依赖，由 GitHub Pages 部署。原小程序不会被覆盖。

## 已实现

修复方向 → 32颗 FDI 牙位同类多选 → 两题偏好 → 五材料推荐 → 自愿信息问卷 → 提交回执。

- 龋齿：抽烟/咖啡＋前牙美观或后牙硬度，1–6分，原八组顺序。
- 牙冠：硬度＋美观，1–6分，原四组顺序，与牙区无关。
- 嵌体：沿用原版当前树脂逻辑，并在入口明确说明。
- 匹配度90/80/70/60/50%，红到蓝；只是偏好排名，不是临床概率。
- 称呼、联系方式、补充需求均选填；查看材料不必提交，未勾选同意不能发送。
- 邮件服务独立运行在 Cloudflare Workers，接收者和密钥仅在服务端。用户选择的主要通知渠道是邮件。

## 本地运行

安装 Node.js 22 或更新版本，在项目目录执行：

```sh
node scripts/dev.mjs
```

打开 http://127.0.0.1:4173/ 。这个预览默认不发送邮件，未配置时会如实显示“提交服务尚未开通”。原始前端目录是 public/，完整构建产物是 dist/。

## 配置边界

- public/config.mjs 与 GitHub Variables 只放公开配置；禁止放邮件 API 密钥或真实收件者。
- .dev.vars 是本地私有配置，已被 Git 忽略；交付压缩包不会包含它。
- 不提交 .env、.dev.vars、.git、qa 测试截图、dist 构建缓存到源代码包。
- 没有表单服务回执不会展示成功；发送失败可以重试，已确认的邮件不重复发送。
